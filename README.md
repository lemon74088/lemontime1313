# 緊湊型多倒數計時面板
https://lemon74088.github.io/lemontime1313/
純 HTML/CSS/JavaScript，適合 GitHub Pages 與 iPhone Safari 加入主畫面。

## 使用
1. 將 `index.html` 上傳到 GitHub repository 根目錄。
2. Repository → Settings → Pages → Build and deployment → Deploy from a branch。
3. Branch 選 `main`，Folder 選 `/ (root)`，Save。
4. 開啟 GitHub Pages 網址。iPhone 使用 Safari → 分享 → 加入主畫面。

## 功能
- 11個預設：1、5、15、30分鐘，1、2、3、4、6、8、12小時。
- 一鍵啟動全部。
- 各時間獨立「關閉」按鈕，關閉清零，不影響其他計時器。
- 剩餘15分鐘黃色、1分鐘橙色、10秒紅色警示。
- 卡片拖曳排序（按「排列」進入模式）。
- 新增自訂時間。
- 本機儲存排列，自訂欄位。
- 不依賴伺服器或第三方套件。

注意：純 HTML 頁面在 iOS 背景中可能被暫停，不能保證鎖屏／背景倒數精確或動態島功能。
